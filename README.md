## 💻 Bidang Fokus dan Tentang Saya

Saya adalah seorang **Pengembang Front-End** yang bersemangat dalam mengubah ide kreatif menjadi antarmuka pengguna (User Interface/UI) yang indah dan fungsional. Berbasis di **Medan**, saya secara aktif mempelajari dan mengasah keterampilan dalam menciptakan:

* **Desain Responsif:** Memastikan tampilan web optimal di berbagai ukuran perangkat.
* **Pengalaman Pengguna (UX) yang Intuitif:** Fokus pada kemudahan navigasi dan interaksi yang menyenangkan.
* **Aplikasi Web Berbasis Komponen:** Menggunakan standar modern untuk struktur kode yang efisien dan modular.

Saat ini, saya sedang dalam proses mendalami **JavaScript** dan *framework* modern (seperti React/Vue/Angular) untuk memperluas kemampuan saya dari hanya *styling* menjadi interaktivitas penuh.
